```python Python (Beta)
from galileo.__future__ import Dataset

# Create a dataset with test data
test_data = [
    {
        "input": "Which continent is Spain in?",
        "output": "Europe",
    },
    {
        "input": "Which continent is Japan in?",
        "output": "Asia",
    },
]

dataset = Dataset(
    name="countries",
    content=test_data
)
dataset.create()
```
