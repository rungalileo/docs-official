## Set up your Anthropic integration

To use an Anthropic LLM to evaluate LLM-as-a-judge metrics, you need to configure an integration.

<Steps>
<Step title="Open the integrations page">
Select the user menu in the top right, then select **Integrations**.

<Columns cols={2}>
![The integrations menu](/snippets/content/get-started/user-menu-integrations.webp)
</Columns>
</Step>
<Step title="Add an Anthropic integration">
Locate the Anthropic option, then select the **+Add Integration** button.

![The add integration button](/snippets/content/get-started/anthropic-integration-selected.webp)
</Step>
<Step title="Add your Anthropic settings">

Set your Anthropic API key. Then select **Save**.

![The Anthropic integrations pane](/snippets/content/get-started/anthropic-integration-api-key.webp)
</Step>
</Steps>
