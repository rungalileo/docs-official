## Check the Log stream

If you check your trace in the Galileo console. You should see a low score for context adherence.

<Steps>
<Step title="Open the Log stream in the Galileo console">
In the Galileo console, select your project, choose the Log stream, and select **View all logs**.
</Step>
<Step title="Select the Traces tab">
You can see the trace that was just logged in the **Traces** tab.

![A logged trace with a 0% context adherence](/snippets/content/get-started/log-stream-traces-low-context-adherence.webp)
</Step>
<Step title="Get more information on the evaluation">
Select the trace to drill down for more information. Use the arrow next to the context adherence score to see an explanation of the metric.

![The trace details with an explanation of the metric](/snippets/content/get-started/trace-messages-low-context-adherence.webp)
</Step>
</Steps>
