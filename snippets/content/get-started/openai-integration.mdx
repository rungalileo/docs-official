## Set up your OpenAI integration

To use an OpenAI LLM to evaluate LLM-as-a-judge metrics, you need to configure an integration.

<Steps>
<Step title="Open the integrations page">
Select the user menu in the top right, then select **Integrations**.

<Columns cols={2}>
![The integrations menu](/snippets/content/get-started/user-menu-integrations.webp)
</Columns>
</Step>
<Step title="Add an OpenAI integration">
Locate the OpenAI option, then select the **+Add Integration** button.

![The add integration button](/snippets/content/get-started/openai-integration-selected.webp)
</Step>
<Step title="Add your OpenAI settings">

Set your OpenAI API key, and optionally your organization Id. Then select **Save**.

![The OpenAI integrations pane](/snippets/content/get-started/openai-integration-api-key.webp)
</Step>
</Steps>
