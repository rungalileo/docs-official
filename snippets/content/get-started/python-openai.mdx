## Prerequisites

To get started with Galileo using Python and OpenAI, you will need:

- A [Galileo account](/getting-started/sign-up), with an [LLM integration configured](/getting-started/sign-up#set-up-your-llm-integration)
- Your [Galileo API key](/getting-started/sign-up#get-your-api-key)
- Your OpenAI API key, and organization Id if applicable
- Python 3.9 or higher installed

## Create your Python project

Now you have your Log stream configured, you are ready to create a Python application to log LLM interactions, and evaluate the response for context adherence.
<br/><br/>
The app you will build is intentionally configured to show a low context adherence score. Later in this guide you will 'fix' it and see the improved evaluation score.

<Steps>

<Step title="Create Project Folder">

<CreateProjectFolder />

</Step>

<Step title="Install Dependencies">

Install the **Galileo SDK** with OpenAI support, and the dotenv package using the following command in your terminal:

<CodeGroup>
```bash Terminal
pip install "galileo[openai]" python-dotenv
```
</CodeGroup>

</Step>

<Step title="Create Project Files">

In your project folder, create a new blank application file and `.env` file:

<CodeGroup>
```python Python
first-AI-evaluation/
│── app.py
│── .env
```
</CodeGroup>

</Step>

<Step title="Set Up Environment Variables">

In your `.env` file, add the following credentials:

<CodeGroup>
<GalileoOpenAIEnvVars/>
</CodeGroup>

<Note>
This assumes you are using a free Galileo account. If you are using a custom deployment, then you will also need to add the URL of your Galileo Console:

```ini .env
GALILEO_CONSOLE_URL=your-Galileo-console-URL
```
</Note>

</Step>

<Step title="Set the values in the .env file">

In the `.env` file, fill in the values:

- `GALILEO_API_KEY` : Set this to the Galileo API key you saved earlier
- `GALILEO_PROJECT` : Set this to the project name you used when creating your new project
- `GALILEO_LOG_STREAM` : Set this to the name of the Log stream you created. If you left this as the default, then set this to `default`.
- `GALILEO_CONSOLE_URL` : Optional. If you are using the free version of Galileo then leave this commented out. Otherwise, set this to the URL of your Galileo custom deployment.
- `OPENAI_API_KEY` : Set this to your OpenAI API key. If necessary, set `OPENAI_BASE_URL` and `OPENAI_ORGANIZATION`.

</Step>
