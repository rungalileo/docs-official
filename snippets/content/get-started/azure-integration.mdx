## Set up your Azure integration

To use an LLM hosted on Azure OpenAI service, or OpenAI models hosted on Azure AI Foundry to evaluate LLM-as-a-judge metrics, you need to configure an integration.

<Steps>
<Step title="Open the integrations page">
Select the user menu in the top right, then select **Integrations**.

<Columns cols={2}>
![The integrations menu](/snippets/content/get-started/user-menu-integrations.webp)
</Columns>
</Step>
<Step title="Add an Azure integration">
Locate the Azure option, then select the **+Add Integration** button.

![The add integration button](/snippets/content/get-started/azure-integration-selected.webp)
</Step>
<Step title="Add your Anthropic settings">

Set your Azure endpoint and API key. Then select **Save**.

![The Azure integrations pane](/snippets/content/get-started/azure-integration-api-key.webp)
</Step>
</Steps>
