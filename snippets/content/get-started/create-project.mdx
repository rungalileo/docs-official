## Create a project

Now you have your integration set up, you can create a project and configure metrics for your Log stream.

Projects allow you to group Log streams and experiments.

<Steps>
<Step title="Create a project">
Select the **+ New Project** button to create a new project.

![The new project button](/snippets/content/get-started/new-project-button.webp)
</Step>
<Step title="Name your project and Log stream">
Give your project a name. Each project needs at least one Log stream, so you can also set the name here, or leave it as the default.

![The create project dialog](/snippets/content/get-started/create-project-dialog.webp)

Once you have set the project and Log stream name, select the **Create project** button to create the project. This project will then be opened.
</Step>
</Steps>
