6. If GPU is needed, confirm the node group has been created with GPU driver installed with command:
How to Confirm
Check for GPU-specific labels: If you are using the NVIDIA GPU Operator or Node Feature Discovery (NFD), your nodes will be automatically labeled. You can check for these labels, which often include the driver version.
sh
kubectl get nodes --show-labels

Verify the NVIDIA device plugin
The NVIDIA device plugin is responsible for exposing the GPUs to your cluster as a schedulable resource. 
List pods in the kube-system namespace: Look for the device plugin pods, which will have a name like nvidia-device-plugin-*.
kubectl get pods -n kube-system | grep nvidia
Check the plugin's logs: If the device plugin is not running or showing errors, check its logs for clues.
kubectl logs -n kube-system <nvidia-device-plugin-pod-name>
Run a test pod with nvidia-smi 
The most definitive way to confirm that everything is working is to deploy a temporary pod that requests a GPU and runs the nvidia-smi command. 
Create a pod manifest: Save the following YAML as gpu-test.yaml: https://drive.google.com/file/d/16cGxBdGS2xQuaX8YrYR5OF8BNVZJ5aWx/view?usp=drive_link 
Deploy the pod: Apply the manifest to your cluster.
Check the pod logs: Once the pod is complete, view its logs. The output of nvidia-smi will confirm that the driver is accessible and show its version.
kubectl logs gpu-test
Clean up the pod: Delete the test pod when you are finished.
kubectl delete pod gpu-test
