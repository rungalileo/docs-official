# Deployment Glossary

This glossary provides definitions for technical terms, acronyms, and concepts used throughout the Galileo deployment documentation.

## A

### ArgoCD

A declarative, GitOps continuous delivery tool for Kubernetes. Used to manage and deploy Galileo applications in your cluster.

### Availability Zone (AZ)

An isolated location within a cloud region. Deploying across multiple AZs provides high availability and fault tolerance.

### Auto-scaling

The automatic adjustment of computational resources based on the current load or demand.

## B

### Backup Retention

The period for which backup copies of data are stored before being automatically deleted.

### Bedrock (AWS)

Amazon Web Services' fully managed service for foundation models, providing API access to various LLMs.

### Blue-Green Deployment

A deployment strategy that uses two identical production environments (blue and green) to minimize downtime and risk.

## C

### CI/CD

Continuous Integration/Continuous Deployment - an automated approach to software development that enables frequent, reliable releases.

### Cluster

A set of worker machines (nodes) that run containerized applications. In Kubernetes context, it's the foundation of your deployment.

### ConfigMap

A Kubernetes API object used to store non-confidential configuration data in key-value pairs.

### Container Registry

A repository for storing and distributing container images (e.g., Docker Hub, Amazon ECR, Google Container Registry).

### Control Plane

The components that manage the Kubernetes cluster, including the API server, scheduler, and controller manager.

## D

### Data Plane

The components responsible for running application workloads, including worker nodes and pods.

### Disaster Recovery (DR)

The process of recovering systems and data after a catastrophic failure or disaster.

### DNS (Domain Name System)

A hierarchical naming system that translates human-readable domain names to IP addresses.

## E

### EBS (Elastic Block Store)

AWS's block-level storage volumes for use with EC2 instances, commonly used for persistent storage in Kubernetes.

### EKS (Elastic Kubernetes Service)

Amazon's managed Kubernetes service that simplifies running Kubernetes on AWS.

### Egress

Outbound network traffic leaving your cluster or network.

### Endpoint

A network address where a service can be accessed, typically consisting of an IP address and port number.

### etcd

A distributed key-value store that serves as Kubernetes' backing store for all cluster data.

## F

### Failover

The automatic switching to a redundant or standby system upon the failure of the primary system.

### Firewall Rules

Network security rules that control incoming and outgoing traffic based on predetermined security policies.

## G

### GKE (Google Kubernetes Engine)

Google Cloud's managed Kubernetes service.

### GitOps

An operational framework that applies DevOps best practices (version control, collaboration, CI/CD) to infrastructure automation.

### Grafana

An open-source analytics and monitoring platform used to visualize metrics from various data sources.

## H

### Helm

A package manager for Kubernetes that helps you define, install, and upgrade complex Kubernetes applications.

### Helm Chart

A collection of files that describe a related set of Kubernetes resources, packaged for easy deployment.

### High Availability (HA)

A system design approach that ensures a high level of operational performance and uptime.

### Horizontal Pod Autoscaler (HPA)

A Kubernetes resource that automatically scales the number of pods based on observed metrics.

## I

### IAM (Identity and Access Management)

Cloud provider service for managing access to resources and services.

### Ingress

An API object that manages external access to services in a cluster, typically HTTP/HTTPS routing.

### Ingress Controller

A component that implements the Ingress resource, handling routing rules and load balancing.

### IOPS

Input/Output Operations Per Second - a performance measurement for storage devices.

## J

### JSON Web Token (JWT)

A compact, URL-safe token format used for securely transmitting information between parties.

## K

### Karpenter

An open-source Kubernetes cluster autoscaler that provisions nodes based on pod requirements.

### Kubernetes (K8s)

An open-source container orchestration platform for automating deployment, scaling, and management of containerized applications.

### kubectl

The command-line tool for interacting with Kubernetes clusters.

### Kubelet

An agent that runs on each node in the cluster, ensuring containers are running in pods.

## L

### Label

Key-value pairs attached to Kubernetes objects for identification and grouping purposes.

### Load Balancer

A device or service that distributes network traffic across multiple servers to ensure no single server is overwhelmed.

### Logging Pipeline

The process flow for collecting, processing, storing, and analyzing log data.

## M

### Managed Service

A cloud service where the provider handles infrastructure management, maintenance, and updates.

### Metrics Server

A cluster-wide aggregator of resource usage data in Kubernetes.

### Multi-AZ Deployment

Deploying resources across multiple availability zones for high availability.

## N

### Namespace

A Kubernetes mechanism for isolating groups of resources within a single cluster.

### Network Policy

Kubernetes specifications that control traffic flow between pods and network endpoints.

### Node

A worker machine in Kubernetes, which can be a physical or virtual machine.

### Node Pool

A group of nodes with the same configuration in a managed Kubernetes service.

## O

### Observability

The ability to measure and understand the internal state of a system based on external outputs.

### OIDC (OpenID Connect)

An identity layer built on top of OAuth 2.0 for authentication.

## P

### PersistentVolume (PV)

A piece of storage in the cluster that has been provisioned by an administrator or dynamically provisioned.

### PersistentVolumeClaim (PVC)

A request for storage by a user, binding to a PersistentVolume.

### Pod

The smallest deployable unit in Kubernetes, consisting of one or more containers.

### Pod Disruption Budget (PDB)

A Kubernetes object that limits the number of pods of a replicated application that can be down simultaneously.

### Prometheus

An open-source monitoring and alerting toolkit designed for reliability and scalability.

## Q

### Quality of Service (QoS)

Kubernetes classification of pods based on resource requests and limits (Guaranteed, Burstable, BestEffort).

## R

### RBAC (Role-Based Access Control)

A method of regulating access to resources based on the roles of individual users.

### Recovery Point Objective (RPO)

The maximum acceptable amount of data loss measured in time.

### Recovery Time Objective (RTO)

The maximum acceptable time to restore a system after a failure.

### Replica

A copy of a pod that Kubernetes maintains for high availability and load distribution.

### ReplicaSet

A Kubernetes controller that ensures a specified number of pod replicas are running at any given time.

### Resource Quotas

Kubernetes constraints that limit resource consumption per namespace.

## S

### SAML (Security Assertion Markup Language)

An XML-based framework for exchanging authentication and authorization data.

### Secret

A Kubernetes object used to store and manage sensitive information like passwords, tokens, and keys.

### Service

A Kubernetes abstraction that defines a logical set of pods and a policy for accessing them.

### Service Mesh

An infrastructure layer that handles service-to-service communication, providing features like load balancing, service discovery, and security.

### SSO (Single Sign-On)

An authentication scheme that allows users to log in with a single set of credentials to access multiple applications.

### StatefulSet

A Kubernetes controller for managing stateful applications, providing stable network identities and persistent storage.

### Storage Class

A Kubernetes resource that describes the "classes" of storage available in a cluster.

## T

### Taints and Tolerations

Kubernetes mechanisms that work together to ensure pods are not scheduled onto inappropriate nodes.

### TLS (Transport Layer Security)

A cryptographic protocol designed to provide secure communication over a network.

### Throughput

The amount of data that can be processed or transmitted in a given time period.

## U

### Upstream

In networking, the direction toward the source or origin of data or requests.

## V

### VPC (Virtual Private Cloud)

A logically isolated section of a cloud provider's infrastructure where you can launch resources.

### Volume

A directory accessible to containers in a pod, used for data persistence.

## W

### Worker Node

A node in a Kubernetes cluster that runs application workloads (pods).

## Cloud Provider Specific Terms

### AWS Terms

- **ELB**: Elastic Load Balancer - AWS's load balancing service
- **RDS**: Relational Database Service - AWS's managed database service
- **S3**: Simple Storage Service - AWS's object storage service
- **VPC Peering**: Connection between two VPCs enabling traffic routing using private IP addresses

### Azure Terms

- **AKS**: Azure Kubernetes Service - Azure's managed Kubernetes offering
- **Resource Group**: A container that holds related resources for an Azure solution
- **Virtual Network**: Azure's isolated network for resource communication
- **Azure Blob Storage**: Azure's object storage solution

### GCP Terms

- **GKE**: Google Kubernetes Engine - Google's managed Kubernetes service
- **VPC Network**: Google Cloud's virtual network
- **Cloud Storage**: Google's object storage service
- **Instance Group**: A collection of VM instances managed as a single entity

## Galileo-Specific Terms

### Console

The Galileo web-based user interface for monitoring, analyzing, and managing LLM applications.

### Experiment

A collection of inference runs used to compare model performance and configurations.

### Log Stream

A real-time sequence of logged events and metrics from your application.

### Luna

Galileo's AI assistant that helps with prompt optimization and model evaluation.

### Metrics

Quantitative measurements used to evaluate LLM performance (e.g., Context Adherence, Hallucination Score).

### Project

A container for organizing related experiments, datasets, and evaluation runs.

### Protect

Galileo's feature for real-time monitoring and guardrails on production LLM applications.

### Trace

A record of a single inference request through your LLM application, including all steps and metrics.

## Monitoring and Observability Terms

### Alert Manager

A component that handles alerts sent by Prometheus, including deduplication and routing.

### DataDog

A monitoring and analytics platform for cloud-scale applications.

### ELK Stack

Elasticsearch, Logstash, and Kibana - a popular log management and analysis solution.

### Grafana Dashboard

A visual representation of metrics and data from various sources.

### Prometheus Query

PromQL expressions used to select and aggregate time series data.

### Splunk

An enterprise platform for searching, monitoring, and analyzing machine-generated data.

## Security Terms

### Certificate Authority (CA)

An entity that issues digital certificates for cryptographic security.

### Encryption at Rest

Protecting data stored on disk or other storage media through encryption.

### Encryption in Transit

Protecting data being transmitted over a network using protocols like TLS.

### Network Segmentation

Dividing a network into smaller parts to improve security and performance.

### Security Group

Virtual firewall rules that control inbound and outbound traffic for cloud resources.

### Zero Trust Architecture

A security model that requires strict identity verification for every person and device.
