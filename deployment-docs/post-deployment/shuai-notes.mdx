Basic Verification
Use kubectl -n galileo get po to confirm all pods are up and healthy

Verify {console_url} is accessible on browser

Verify {api_url}/healthcheck and {console_url}/api/galileo/healthcheck are accessible on browser

If console is accessible from public internet, add {console_url}/api/galileo/healthcheck to synthetics probes on grafana cloud (link), so we get alerts when it’s down

Sign up the first user on {console_url}/sign-up

Test SSO if it’s enabled

Invite another user, confirm they can sign in

Create project/prompt/dataset/prompt/metric/integration/experiment

Make sure an experiment can be run e2e and metrics can be computed

At least one of TS_TESTS or PY_TESTS must be provided.

TS_TESTS (optional): one or more Playwright paths/patterns inside ts-sdk-and-ui (comma-separated), e.g., ui/tests/projects/projects.spec.tsx,ui/tests/datasets/create-dataset.spec.tsx

PY_TESTS (optional): one or more pytest targets inside py-sdk-and-ui (comma-separated), e.g., tests/test_datasets.py,tests/test_metrics.py
