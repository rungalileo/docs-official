## Welcome to Galileo Deployment Documentation

This documentation provides comprehensive guides for deploying the Galileo Platform on your own infrastructure. Galileo is designed to run on Kubernetes clusters across major cloud providers and on-premise environments.

<Info>
  **Total deployment time:** 30-60 minutes depending on your cloud provider and configuration complexity.
</Info>

## Deployment Options

Galileo supports deployment on the following platforms:

  <Card title="AWS EKS" icon="aws" href="/deployment-docs/deploying-on-aws-eks">

## What You'll Need

Before starting your deployment, ensure you have:

<CardGroup cols={3}>
  <Card title="Kubernetes Cluster" icon="dharmachakra">
    Version 1.25 or higher with persistent volume support
  </Card>
  <Card title="Resources" icon="gauge-high">
    Sufficient CPU, memory, and storage for your workload size

  <Card title="Access & Tools" icon="terminal">
    kubectl, helm, and cloud provider CLI tools installed

</CardGroup>

Follow this recommended path for a successful deployment:

<Steps>
  <Step title="Review Prerequisites">

## Key Features

### Multi-Cloud Support
Deploy Galileo on AWS, Google Cloud, Azure, or any Kubernetes-compatible platform with consistent configurations.

### Helm-Based Deployment
Leverage Helm charts for reproducible, version-controlled deployments with easy upgrades and rollbacks.

### Enterprise Security
Built-in support for SSO, RBAC, encryption at rest and in transit, and compliance with security standards.

### Scalable Architecture
Auto-scaling capabilities for compute resources with support for GPU workloads and high-availability configurations.

### Managed Services Integration
Optional integration with managed databases (RDS, Cloud SQL, Azure Database), object storage, and Redis.
