# Galileo Deployment Decision Guide

This interactive guide will help you quickly determine the best deployment configuration for your Galileo Platform installation.

## 🎯 Start Here: Quick Decision Tree

<Steps>
  <Step title="Determine Your Deployment Tier">
    Answer these questions to identify your deployment tier:
    <Accordion title="Do you need complete infrastructure control?">
      **Yes** → Consider **Tier 3** or **Tier 4** - Tier 3: Customer-managed
      cloud with Galileo support - Tier 4: Fully air-gapped, self-managed
      deployment **No** → Consider **Tier 1** or **Tier 2** - Tier 1: Fully
      hosted by Galileo - Tier 2: Galileo-managed in your cloud account
    </Accordion>
    <Accordion title="Do you have strict data residency requirements?">
      **Yes** → You need **Tier 2**, **Tier 3**, or **Tier 4** - Your data stays
      in your infrastructure **No** → **Tier 1** (fully hosted) is an option
    </Accordion>
    <Accordion title="Can your environment access the internet?">**No** → You need **Tier 4** (air-gapped deployment) **Yes, but restricted** → **Tier 3** with firewall rules **Yes, unrestricted** → Any tier works for you</Accordion>
  </Step>

## ❓ Common Decision Points

<AccordionGroup>
  <Accordion title="Should I use managed databases or self-host?">
    **Use Managed Databases if:** - You want automatic backups and high
    availability - You have limited database administration expertise - You need
    compliance certifications - Cost is less important than reliability
    **Self-Host Databases if:** - You need full control over configuration - You
    have database administration expertise - You're in an air-gapped environment
    - You want to minimize external dependencies
  </Accordion>

  <Accordion title="How many GPU nodes do I need?">
    **GPU Requirements by Use Case:** - **No ML Evaluations**: 0 GPU nodes
    needed - **Light ML Usage** (Luna evaluations): 1 GPU node - **Heavy ML
    Usage**: 2-4 GPU nodes - **Fine-tuning Workflows**: 4+ GPU nodes **GPU Node
    Recommendations:** - AWS: p3.2xlarge or g4dn.xlarge - GCP: n1-standard-8
    with T4 or A100 - Azure: NC6s_v3 or NC12s_v3
  </Accordion>

  <Accordion title="What about high availability and disaster recovery?">
    **High Availability Options:** - **Tier 1**: Built-in HA with 99.9% SLA -
    **Tier 2**: Multi-AZ deployment, managed failover - **Tier 3**: Configure
    your own HA (multi-zone, replicas) - **Tier 4**: Manual HA configuration
    required **Disaster Recovery:** - All tiers support automated backups - Tier
    2-4: Cross-region backup options - RTO: 1-4 hours depending on tier - RPO:
    1-24 hours based on backup frequency
  </Accordion>

  <Accordion title="Can I change tiers later?">
    **Yes, you can migrate between tiers:** - **Tier 1 → 2**: Export data,
    deploy in your cloud - **Tier 2 → 3**: Transfer management responsibility -
    **Tier 3 → 4**: Implement air-gap procedures - **Any → Tier 1**: Import data
    to hosted platform Migration typically takes 2-8 hours with minimal
    downtime.
  </Accordion>
</AccordionGroup>
