## Overview

This guide explains how to integrate Galileo with [OpenTelemetry](https://opentelemetry.io/) and [OpenInference](https://github.com/Arize-ai/openinference) for comprehensive observability and tracing of your AI/ML workflows using industry-standard tools.

## OpenTelemetry instrumentation steps

To implement OpenTelemetry with Galileo, you'll need to complete these essential steps:

1. **Install dependencies** - Add OpenTelemetry packages and AI instrumentation libraries
2. **Configure the OTel endpoint** - Set up the exporter to send traces to Galileo's OTel endpoint
3. **Set up authentication headers** - Format your Galileo API key and project information for OTel
4. **Configure the tracer provider** - Assemble the complete observability system with service metadata
5. **Apply AI instrumentation** - Enable automatic tracing for LangChain and OpenAI operations

Galileo supports multiple ways to instrument OpenTelemetry with different AI frameworks or LLMs. Choose the method that best fits your application:
