## Overview

Galileo provides an integration with **OpenTelemetry** and **OpenInference** standards, enabling you to capture, trace, and analyze your AI/ML workflows with industry-standard observability tools.

### What is OpenTelemetry

[OpenTelemetry](https://opentelemetry.io/), or OTel, is a collection of APIs, SDKs, and tools that provide observability for cloud-native software. It allows you to collect telemetry data (traces, metrics, and logs) from your applications and send it to various backends for analysis.

### What is OpenInference

[OpenInference](https://github.com/Arize-ai/openinference) is an open standard for AI/ML observability that extends OpenTelemetry with specialized semantic conventions for AI/ML workloads. It provides structured schemas for capturing AI-specific telemetry data.

## Benefits of integration

- **Standardized Observability**: Use industry-standard tools and practices
- **Vendor Neutrality**: Avoid vendor lock-in with open standards
- **Rich Context**: Capture detailed AI/ML specific telemetry
- **Tool Ecosystem**: Leverage the vast OpenTelemetry ecosystem
- **Compliance**: Meet observability requirements with proven standards
