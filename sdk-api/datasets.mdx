## Dataset fields

Each record in a Galileo dataset can have three top-level fields: 

1. **`input`** - Input variables that can be passed to your application to recreate a test case.
2. **`output`** - Reference outputs to evaluate your application. These can be the ground truth for [BLEU, ROUGE](/concepts/metrics/expression-and-readability/bleu-and-rouge), and [Ground Truth Adherence](/concepts/metrics/response-quality/ground-truth-adherence) metrics, or reference outputs for manual reference.
3. **`metadata`** - Additional data you can use to filter or group your dataset.
