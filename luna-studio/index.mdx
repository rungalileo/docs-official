Luna Studio is Galileo's end-to-end environment for creating custom evaluation metrics tuned to your AI system. Use the **UI** when you want a guided workflow in the web app, or use the **SDK** when you want to generate data, train, evaluate, and deploy metrics in code.

## What each section covers

### UI

The UI docs focus on the web application experience: integrations, datasets, projects, training runs, metric registration, and troubleshooting for the hosted workflow.

### SDK

The SDK docs focus on programmatic workflows: installation, config structure, data generation, training, tutorials for supported input formats, and deployment steps.
