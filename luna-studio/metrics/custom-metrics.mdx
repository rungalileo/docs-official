title: "Custom metrics"
description: "Define a metric with a custom LLM-as-judge prompt, outside of a training run."
---

Most metrics in Luna Studio are created implicitly when you launch a [training run](/luna-studio/runs/new-run/overview). But sometimes you want to define a metric directly — for example, to draft a prompt before launching a run, or to publish a prompt-based metric without fine-tuning.

The **Create custom metric** modal handles this case.

<Frame caption="Custom metric, new-run wizard — Metric step with Custom prompt selected">
  ![Custom metric in the new-run wizard](/images/luna-studio/metrics/create-custom-metric.png)
</Frame>

## Open the modal

From the [Metrics page](/luna-studio/metrics/overview), click **Create custom metric** in the top right.

The modal title is **Create custom metric** with the subtitle "Define how Luna should evaluate your model. You can register the metric once it is fine-tuned on your test set."

## Fields

| Field       | Required | Notes                                                                                             |
| ----------- | -------- | ------------------------------------------------------------------------------------------------- |
| Metric name | Yes      | A descriptive name (e.g. `toxicity-strict`).                                                      |
| Output type | Yes      | The metric's return shape: Boolean, Floating Point, Categorical, Percentage, Multilabel, Numeric. |
| Step        | Yes      | The trace step the metric runs against: LLM span, Retriever, Agent span, Trace.                   |
| Modality    | —        | Read-only. Fixed to **Text** today.                                                               |
| Prompt      | Yes      | The LLM-as-judge prompt. Required.                                                                |

## Output types in detail

| Output type    | When to use                                                             |
| -------------- | ----------------------------------------------------------------------- |
| Boolean        | Yes/no questions ("Is this toxic?", "Does the answer cite a source?").  |
| Floating Point | Confidence scores, similarity scores, anything continuous.              |
| Categorical    | Picking one of a fixed list (e.g. `positive` / `neutral` / `negative`). |
| Percentage     | A 0–100 score (e.g. "How complete is this answer?").                    |
| Multilabel     | Multiple categorical labels per input (e.g. `tone,grammar,policy`).     |
| Numeric        | Open-ended numeric answers.                                             |

The output type also constrains what label values your test set can use during validation. See [Test sets](/luna-studio/datasets/test-sets#required-schema).

## Steps in detail

| Step       | Where it fires                                                 |
| ---------- | -------------------------------------------------------------- |
| LLM span   | A single LLM call inside a trace. The default and most common. |
| Retriever  | A retrieval step (e.g. evaluating chunk relevance).            |
| Agent span | A single agent step inside a trace.                            |
| Trace      | The full trace — input, intermediate steps, and final output.  |

The right step depends on what your metric needs to see. For "is the final answer toxic?" → LLM span or Trace. For "are retrieved chunks relevant?" → Retriever.

## Prompt-writing tips

- **Be specific.** Define exactly what counts as a positive vs negative result.
- **Give examples.** One or two short examples per outcome class is plenty.
- **Constrain the output.** End the prompt with something like "Respond with only `true` or `false`." for Boolean metrics.
- **Avoid open scales.** "Score 1–10" is harder for an LLM-judge to keep consistent than a binary or 3-class categorical.

## Submit

Click **Create metric**. The new metric appears in the [Metrics table](/luna-studio/metrics/overview) with status **Queued** if you also kicked off a training run, or as a draft otherwise (depending on what you do next).

## Custom metric inside the new-run wizard

There's a parallel path inside [Step 1 of the new-run wizard](/luna-studio/runs/new-run/step-1-metric#write-a-custom-prompt) that creates a custom metric scoped to the run. Use that flow if you're planning to fine-tune the prompt right away. Use the standalone **Create custom metric** flow when you want to define the metric definition without immediately fine-tuning.
