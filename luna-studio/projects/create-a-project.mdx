You can create a project two ways: from the **Projects** page (the most common path) or as the second step of [onboarding](/luna-studio/onboarding/overview) on first sign-in.

<Frame caption="Create new project modal">
  ![Create new project modal](/images/luna-studio/projects/new-project-modal.png)
</Frame>

## From the Projects page

<Steps>
<Step title="Open the Projects page">
  Click **Projects** in the sidebar (or the Luna Studio logo).
</Step>

<Step title="Click New project">
The primary button in the top right of the page header. The **Create new project** modal opens.
</Step>

<Step title="Enter a project name">
  The field is labelled **Project name** with the placeholder `my-project`.

  <Tip>
    Project names are checked for duplicates inline — if you type a name that already exists, an error appears below the field and the **Create** button is disabled until you change it.
  </Tip>

</Step>

<Step title="Click Create">
  Luna Studio creates the project and routes you to its [Training runs](/luna-studio/projects/training-runs-home) page, ready for your first run.
</Step>
</Steps>

## Naming conventions

There's no strict format, but a few patterns work well:

- **Application + metric** &mdash; `support-tone-classifier`, `rag-grounded-answers`.
- **Domain + metric** &mdash; `legal-pii-detector`, `medical-toxicity`.
- **Versioned** &mdash; `summarizer-v2`, `rag-evaluator-v3` for iterating on the same metric.

Avoid spaces (use hyphens or underscores) and keep names short — they appear in breadcrumbs throughout the app.

## What happens behind the scenes

Creating a project does **not** consume any quota or trigger any external API calls. It just provisions a container — the first time you launch a run inside it, Luna Studio uses the integrations you've already configured.

## What to do next

Inside the new project, head to the **Training runs** page (you're already there) and click **New run** to launch your first training. The flow is documented in detail at [New run wizard overview](/luna-studio/runs/new-run/overview).
