The **Galileo integration** is a special integration card in the **Galileo Integration** category on the [Integrations](/luna-studio/integrations/overview) page. It's a single API key that connects Luna Studio to the rest of the Galileo platform.

<Frame caption="The Galileo integration card sits in its own section above the LLM providers">
  ![Galileo integration card on the Integrations page](/images/luna-studio/integrations/integrations-page.png)
</Frame>

## Why you'd add it

The Galileo integration unlocks two flows that don't work without it:

- **Import from Galileo** &mdash; pull datasets from your Galileo workspace into Luna Studio. Available in the [Add dataset modal](/luna-studio/datasets/add-a-dataset) and in [Step 2](/luna-studio/runs/new-run/step-2-test-set) and [Step 3](/luna-studio/runs/new-run/step-3-training-set) of the new-run wizard.
- **Register metric** &mdash; publish a fine-tuned metric from Luna Studio into the Galileo metrics store, where it becomes available across evaluation, observability, and guardrails. See [Register a metric](/luna-studio/runs/register-metric).

You can use Luna Studio without the Galileo integration — uploads, URL fetches, and local-only flows work fine — but registration and Galileo-sourced data require it.

## Add the integration

<Steps>
  <Step title="Open the Integrations page">
    From the sidebar footer, click **Integrations**.
  </Step>

<Step title="Find the Galileo card">
  It lives under the **Galileo Integration** section, below the LLM providers.
</Step>

<Step title="Click Add integration">A modal opens titled **Galileo integration**.</Step>

<Step title="Paste your Galileo API key">
  Get your key from the Galileo console. The field is a password input — the key is masked.
</Step>

  <Step title="Click Save changes">
    The card flips to **Active**.
  </Step>
</Steps>

## Inline prompt during dataset flows

If you click **Import from Galileo** in any dataset modal without an active Galileo integration, Luna Studio transparently opens the Galileo integration modal first. Save credentials there and the dataset flow resumes where you left off.

If you cancel the integration modal without saving, the dataset source selection is cleared and you can pick a different source.

## Update or remove

- **Update** &mdash; reopens the modal pre-filled. Pasting a new key overwrites the previous one.
- **Remove** &mdash; opens a confirmation dialog. Removing disables Import from Galileo and Register metric across the org.

<Warning>
  Removing the Galileo integration **does not unregister** any metrics already published to the
  Galileo metrics store. Those metrics remain live until you remove them from the Galileo platform
  itself.
</Warning>
