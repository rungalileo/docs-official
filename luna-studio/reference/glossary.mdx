Alphabetical reference for every concept and UI element in Luna Studio. For the conceptual map and how these terms relate, see [Core concepts](/luna-studio/core-concepts).

## A

**Advanced settings** &mdash; Collapsed accordion in the [Generate from test set drawer](/luna-studio/runs/new-run/step-3-training-set#generate-from-test-set) where future generation knobs (temperature, max tokens) will live. Placeholder today.

**Agent span** &mdash; A trace step representing a single agent action. One of four metric steps (LLM span, Retriever, Agent span, Trace).

**Assumed Role** &mdash; AWS authentication mode using a role ARN instead of an access key. Used in the [AWS Bedrock and SageMaker integrations](/luna-studio/integrations/aws-bedrock-sagemaker).

## B

**Base model** &mdash; The Luna model that gets fine-tuned during a run. One of Luna Small, Luna Medium, or Luna Large. See [Luna-2](/concepts/luna/luna) for model details.

**Boolean** &mdash; A metric output type that returns true or false.

## C

**Categorical** &mdash; A metric output type that returns one of a fixed set of labels.

**Custom metric** &mdash; A metric defined by a user-authored prompt rather than a predefined template. Created via [Create custom metric](/luna-studio/metrics/custom-metrics).

**Custom prompt** &mdash; The dropdown action in [Step 1 of the new-run wizard](/luna-studio/runs/new-run/step-1-metric) that switches the metric to user-authored.

## D

**Dataset** &mdash; A general term covering both [test sets](/luna-studio/datasets/test-sets) and [training sets](/luna-studio/datasets/training-sets).

**Dataset preview** &mdash; The 100-row table shown on the dataset details page. See [Dataset details](/luna-studio/datasets/dataset-details).

## E

**Evaluation** &mdash; Running a metric against a labelled test set to compute scores like F1, AUC-ROC, or accuracy.

## F

**Fine-tuned** &mdash; A run lifecycle status meaning training succeeded and the metric is ready to be registered. See [Run lifecycle](/luna-studio/runs/lifecycle).

**Floating Point** &mdash; A metric output type that returns a real number in a range.

## G

**Galileo integration** &mdash; The Galileo API key configured in [Integrations](/luna-studio/integrations/galileo). Required for "Import from Galileo" dataset sources and metric registration.

**Generate from test set** &mdash; Training-set source that uses an LLM to synthesize a labelled training set from your test set. See [Step 3](/luna-studio/runs/new-run/step-3-training-set#generate-from-test-set).

## I

**Import from Galileo** &mdash; Dataset source that pulls rows from your connected Galileo workspace. Requires the [Galileo integration](/luna-studio/integrations/galileo).

**Input** &mdash; The required column on every dataset, holding the text the metric scores.

**Integration** &mdash; An org-scoped credential bundle for an external service (LLM provider or Galileo). See [Integrations](/luna-studio/integrations/overview).

## L

**Label** &mdash; The required column on a labelled dataset, holding the ground-truth value the metric should learn.

**LLM span** &mdash; A trace step representing a single LLM call. The default metric step.

**Luna Small / Medium / Large** &mdash; The three [base models](/luna-studio/core-concepts#base-models) you can fine-tune. They are variants of the [Luna-2](/concepts/luna/luna) SLM.

## M

**Metric** &mdash; A function that scores some part of an LLM trace. See [Metrics overview](/luna-studio/metrics/overview).

**Modality** &mdash; The data type a metric operates on. Today, all Luna Studio metrics use the **Text** modality.

**Multilabel** &mdash; A metric output type that returns multiple categorical labels per input.

## N

**Numeric** &mdash; A metric output type that returns an unbounded real number.

## O

**Onboarding** &mdash; The two-step first-run wizard that captures an LLM provider and creates a first project. See [Onboarding overview](/luna-studio/onboarding/overview).

**Output type** &mdash; The shape of a metric's return value. One of Boolean, Floating Point, Categorical, Percentage, Multilabel, Numeric.

## P

**Percentage** &mdash; A metric output type that returns a number between 0 and 100.

**Project** &mdash; A container for related training runs. See [Projects overview](/luna-studio/projects/overview).

## Q

**Queued** &mdash; A run lifecycle status meaning the run is accepted but training hasn't started.

## R

**Register** &mdash; The act of publishing a fine-tuned metric to the Galileo metrics store so it's available for evaluation, observability, and guardrails. See [Register a metric](/luna-studio/runs/register-metric).

**Registered** &mdash; A run lifecycle status meaning the metric has been published to the Galileo metrics store.

**Retriever** &mdash; A trace step representing a single retrieval operation. One of four metric steps.

**Run** &mdash; Short for [training run](/luna-studio/core-concepts#training-runs).

## S

**Sample dataset** &mdash; The first ~200 generated rows you review before kicking off the full training-set generation. See [Step 3](/luna-studio/runs/new-run/step-3-training-set#generate-from-test-set).

**Source** &mdash; Where a dataset came from: Upload, URL, or Galileo. Shown as a column on the [Datasets page](/luna-studio/datasets/overview).

**Step** &mdash; The trace step a metric operates on (LLM span, Retriever, Agent span, Trace). Distinct from a "wizard step".

## T

**Test set** &mdash; A small labelled dataset used to evaluate a fine-tuned metric. See [Test sets](/luna-studio/datasets/test-sets).

**Trace** &mdash; A trace step representing the full LLM request/response. One of four metric steps.

**Training run** &mdash; A single fine-tuning attempt. See [Run lifecycle](/luna-studio/runs/lifecycle).

**Training set** &mdash; The dataset used to fine-tune the base model. See [Training sets](/luna-studio/datasets/training-sets).

## V

**Validation** &mdash; The schema and content checks Luna runs on every dataset. See [Validation](/luna-studio/datasets/validation).

## W

**Wizard** &mdash; The four-step new-run flow. See [New run wizard](/luna-studio/runs/new-run/overview).
