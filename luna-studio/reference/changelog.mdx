## Unreleased

The following features are tracked for upcoming releases.

### Coming soon

- **Run details charts** &mdash; ROC and PR curves on the Run details page, alongside the existing metrics grid.
- **Generation knobs** &mdash; "Advanced settings" on the Generate from test set drawer will expose sampling parameters (temperature, max tokens, top-K, top-P).
- **Server-persisted onboarding state** &mdash; the per-org onboarding-dismissed flag will move from the browser to your account so it persists across devices.
- **Run cancellation** &mdash; cancel a run in the **Training** state without waiting for completion.

## v0 — initial preview

Initial preview release of Luna Studio. Highlights:

### Account and onboarding

- Email + password account setup, sign-in, and password reset in [Set Up Your Account](/luna-studio/account/setup-account).
- Two-step [onboarding wizard](/luna-studio/onboarding/overview) for first-time users (LLM provider + first project).

### Integrations

- Runtime integrations for supported model providers and Galileo.
- Galileo integration for dataset import and metric registration.

### Projects and runs

- Project [home](/luna-studio/projects/training-runs-home) with status summary, filters, and starring.
- Four-step [run creation flow](/luna-studio/runs/new-run/overview): Metric → Test set → Training set → Config and launch.

### Datasets

- Test sets and training sets, both [org-scoped](/luna-studio/datasets/overview).
- Three sources: Upload (`.csv`/`.jsonl`), Fetch from URL (http/https/s3/gs), Import from Galileo.
- "Generate from test set" flow that reviews 50 sample rows and synthesizes 2,000 labelled training examples.
- Validation pipeline with four states (Validating / Validated / Validated with warnings / Validation error).

### Metrics

- Metric picker groups for Galileo presets, custom Galileo metrics, and saved custom prompts.
- [Custom metrics](/luna-studio/metrics/custom-metrics) with Boolean and Categorical output types and text-only training support.
- [Register metric](/luna-studio/runs/register-metric) flow that publishes fine-tuned metrics to the Galileo metrics store.

## How to read this changelog

- **Unreleased** &mdash; features in development. Behavior may change before launch.
- **v0** &mdash; initial preview release. Behavior is stable but the API surface is private.

For the latest, see the in-product release notes (when available) or follow the [Galileo blog](https://galileo.ai/blog).
