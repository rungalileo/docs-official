The first step asks: _what should this metric measure?_ You can pick from a curated list of templates, or click **Use custom prompt** to write your own.

<Frame caption="Step 1 — pick a built-in metric or define your own with a custom prompt">![Metric step](/images/luna-studio/runs/new-run-metric.png)</Frame>

## Pick a predefined metric (Recommended)

The **Metric** select is searchable. You can find all LLM-as-judge metrics available in your Galileo console here, including any custom metrics you've created. The preset metric options are organized into three groups:

### RAG Quality

| Template          | What it measures                                                 |
| ----------------- | ---------------------------------------------------------------- |
| Context adherence | Whether the answer sticks to the retrieved context.              |
| Chunk relevance   | Whether each retrieved chunk is relevant to the query.           |
| Context relevance | Whether the retrieved context is sufficient to answer the query. |

### Safety & security

| Template         | What it measures                                                         |
| ---------------- | ------------------------------------------------------------------------ |
| Toxicity         | Whether the response contains toxic, harmful, or offensive content.      |
| Sexism / bias    | Whether the response contains sexist, biased, or discriminatory content. |
| Prompt injection | Whether the response is a prompt injection.                              |
| Tone             | Measures the emotional tone and style of the response.                   |

### Agentic

| Template               | What it measures                                                     |
| ---------------------- | -------------------------------------------------------------------- |
| Correctness            | Whether the response is factually correct.                           |
| Instruction adherence  | Whether the response follows the instructions in the prompt.         |
| Tool error rate        | Whether the response contains tool errors.                           |
| Tool selection quality | Whether the response selects the most appropriate tool for the task. |

## Inspect a selected template

Once you pick a template, the form expands to show a read-only **Metric details** panel:

- **Output type** &mdash; the metric's return shape (Boolean, Categorical etc.). See [Output types](/luna-studio/core-concepts#metrics).
- **Step** &mdash; the trace step the metric runs against (LLM span, Retriever span, Trace input / output only).
- **Prompt** &mdash; the LLM-as-judge prompt the template uses, in a read-only textarea.

## Write a custom prompt

For metrics that don't fit a template, click the dropdown's **Use custom prompt** option (with a `+` icon). The form switches into editable mode.

<Frame caption="Step 1 with Custom prompt expanded — write your own LLM-as-judge prompt for the metric">![Custom metric prompt](/images/luna-studio/runs/new-run-metric-custom.png)</Frame>

In custom mode, you fill in:

| Field       | Notes                                                       |
| ----------- | ----------------------------------------------------------- |
| Output type | Pick one of Boolean / Categorical                           |
| Step        | Pick LLM span / Retriever span / Trace input / output only. |
| Prompt      | The LLM-as-judge prompt [required].                         |

<Tip>
  **Pro tip:** For best results, we recommend first creating your metric in the Galileo console and using the **Autotune** feature to test and refine it on a labelled test dataset. This helps you optimize the metric’s performance before
  launching a full training run in Luna Studio.
</Tip>
