The training set is the dataset that fine-tunes your base model — typically much larger than the test set (~3,000 rows vs. a few hundred). You have two options for sourcing it.

<Frame caption="Step 3 — pick a training data source: generate from your test set or add training logs">![Training set step](/images/luna-studio/runs/new-run-training-set.png)</Frame>

## The 3 training dataset sources

The step opens with a section heading **Training data source** and three selectable cards:

<CardGroup cols={2}>
  <Card title="Generate from test set" icon="wand-magic-sparkles">
    Uses 20% of your test set as seed examples to generate ~3,000 labelled training samples via a synthetic dataset generator. **Recommended for first runs.**
  </Card>
  <Card title="Add training logs" icon="upload">
    Upload or import your own raw production logs (labelled or unlabelled). If they are unlablled, Luna Studio will use the LLM-as-judge prompt to label these logs and use them for training.
  </Card>
</CardGroup>

Pick one — clicking either card opens its respective sub-flow.

## Generate from test set

This option uses a synthetic dataset generator to create a training set from your test set. You will have 3 steps -

1. Configure the generator and generate a sample dataset
2. Review the sample data and provide feedback to the generator
3. Generate the final dataset once you are happy with the samples

### Configure the generator

The generator is configured with the following settings:

<Frame caption="Generate from test set drawer, configure phase — pick a model and dataset name before generating samples">![Generate drawer, config phase](/images/luna-studio/runs/new-run-generate-config.png)</Frame>

| Field                | Notes                                                                                                                                                            |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Test set (read-only) | Shows your selected test set with the caption "Uses 20% of test set as seed examples".                                                                           |
| Model                | The LLM that generates the training samples. Options: depends on the LLM provider you have configured. Using larger models is preferred for better quality data. |
| Output dataset name  | Provide a name for the output dataset like `project-ABC-metric-PQR-training-set-v1`. Defaults to `generated-training-set`.                                       |
| Metric (read-only)   | Includes a **View prompt** popover so you can re-check the metric prompt.                                                                                        |
| Advanced settings    | Some advanced knobs to try (Not recommended for first runs)                                                                                                      |

Click **Generate sample dataset** at the bottom of the drawer, once you are happy with the settings.

### Review the sample data

<Frame caption="Generate from test set drawer, review phase — approve sample rows or regenerate before kicking off the full run">![Generate drawer, review phase](/images/luna-studio/runs/new-run-generate-review.png)</Frame>

You're reviewing ~200 sample rows before kicking off the full generation.

#### Provide feedback and Regenerate samples

You can provide feedback by selecting the rows that look wrong and clicking the **Regenerate** button. Once you click the button, the **Regenerate dataset** modal opens with a radio group of reasons:

| Reason                     | When to pick it                                                  |
| -------------------------- | ---------------------------------------------------------------- |
| Samples are too repetitive | The generated rows look almost identical to each other.          |
| Labels look incorrect      | The labels don't match what the inputs deserve.                  |
| Inputs are off-topic       | The inputs don't reflect the kind of data your application sees. |
| Provide own feedback       | Free-form text — describe what's wrong in your own words.        |

Click **Regenerate** to kick off another sample generation.

The **Regenerate** button in the modal stays disabled until either a reason is picked or, for "Provide own feedback", the text is non-empty.

Note - you can provide feedback upto 3 times. You can also track the cycles in the UI.

#### Generate the final dataset

Once you're happy with the samples, the footer button changes to **Generate final dataset** (enabled once selection > 0). Clicking it kicks off the full ~3,000-row generation. When it completes, the drawer closes and Step 3 shows the **Training set completed** view (see below).

## Add training logs

The other path is **Add training logs** — uploading or importing your own labelled (or unlabelled) production logs.

Clicking the card opens the **Add training set** modal — the same generic dataset source modal used elsewhere in the app, with three sources:

<CardGroup cols={3}>
  <Card title="Upload from local" icon="upload">
    Drag-and-drop a `.csv` or `.jsonl` file.
  </Card>
  <Card title="Fetch from URL" icon="link">
    Paste an `http://`, `https://`, `s3://`, or `gs://` URL.
  </Card>
  <Card title="Import from Galileo" icon="cloud-arrow-down">
    Browse datasets in your connected Galileo workspace.
  </Card>
</CardGroup>

### Validation

Luna Studio runs validation on the training set to ensure it meets the required schema / format / content rules.
If there are any validation errors, they will be highlighted (See example below).

For more details, see [Validation](/luna-studio/datasets/validation).

## Training set completed
