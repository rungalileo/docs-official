This guide assumes you have:

- [A Galileo account](https://app.galileo.ai), and an [API key](https://app.galileo.ai/settings/api-keys)
- An [Open AI API key](https://platform.openai.com/api-keys)
- Python or TypeScript configured


```bash TypeScript

```

<Step title="Create a .env file">

Create a `.env` file with the following settings. Set your Galileo API key, project name, Log stream name, and your OpenAI API key.

If you are using the free version of Galileo, leave the `GALILEO_CONSOLE_URL` as `https://app.galileo.ai`, otherwise update this to your deployment URL.

<CodeGroup>
```ini .env

GALILEO_PROJECT="your-galileo-project-name"
GALILEO_LOG_STREAM="your-galileo-log-stream"
GALILEO_CONSOLE_URL=https://app.galileo.ai

OPENAI_API_KEY="your-openai-api-key"
```

## Troubleshooting

- **I need a Galileo API key**: Head to [app.galileo.ai](https://app.galileo.ai) and sign up. Then head to the [API keys](https://app.galileo.ai/settings/api-keys) page to get a new API key.
- **What's my project name and Log stream name?**: The project and Log stream names were set when you created a new project. If you haven't created a new project, head to Galileo and select the **New Project** button.
- **I don't have an OpenAI key**: Galileo supports any LLM, with the OpenAI SDK the easiest to get started with. You can spin up an [Ollama](https://ollama.com) instance and use the code above with it, or manually log using any LLM. Check out the [logger documentation](/sdk-api/logging/logging-basics) for more details.
- **I don't see any metrics**: For Galileo to calculate metrics, you need to add an [LLM integration](/getting-started/sign-up#set-up-your-llm-integration), and [turn on metrics for the Log stream](/getting-started/quickstart#configure-metrics-for-your-log-stream). Once done, re-run your app and you will see metrics being calculated.
