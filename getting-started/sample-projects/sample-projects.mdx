When you create a new Galileo account, you get a set of sample projects, pre-populated with Log streams, calculated metrics, and insights.

These projects are:

- A simple terminal-based chatbot to chat with an LLM
- A multi-agent financial services chatbot with LangGraph

You can use the sample projects to learn how to navigate Log streams, understand metrics, use insights, log your AI applications, or run experiments in code.
