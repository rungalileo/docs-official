## Logging your First Trace

This guide uses the **Galileo SDK** to create a simple trace, and the **Galileo Console** to inspect the trace for evaluation.

Follow these **3 steps** to log the first trace with Galileo.

<Steps>

<Step title="Install Galileo SDK">

Install the **Galileo SDK** with OpenAI support.

<CodeGroup>
```bash Python
pip install "galileo[openai]"
```

```bash TypeScript
npm install galileo --save
```
</CodeGroup>

</Step>

<Step title="Create Log stream and Project in the Galileo UI">

Follow these steps to set up your Galileo environment:

1. Go to the [Galileo UI Console](https://app.galileo.ai/) and create an account.

2. After logging in, create an organization (if you haven't done so already!)

3. Within your organization, **create a Project and Log stream**:
   - Create a new project (e.g., "My First AI Project")
   - Create a log stream (e.g., "dev", "demo", "experimental")

<Note>
Set the project and log stream names as environment variables in your dev environment.
```
export GALILEO_PROJECT="Your Project Name"
```
```
export GALILEO_LOG_STREAM="Your Log Stream Name"
```
</Note>

4. [Generate a Galileo API key](https://app.galileo.ai/settings/api-keys) and set it as an environment variable in your dev environment.

<CodeGroup>
```
export GALILEO_API_KEY="YOUR API KEY"
```
</CodeGroup>

5. Finally, set your OpenAI API Key. If you don't have one, create one on the [Open AI Developer's Portal](https://platform.openai.com/api-keys).
<CodeGroup>
```
export OPENAI_API_KEY="YOUR OPENAI API KEY"
```
</CodeGroup>

</Step>

### Configure a Metric: Instruction Adherence

Click "Configure Metrics" on the right to open the menu of built-in **Metrics**.

[Metrics](/concepts/metrics) are used to evaluate and track the performance of AI models in your experiments.

![Configure Metrics](/images/console-ui/metrics-open.png)

#### Enabling the Metric
Click the toggle next to "Instruction Adherence" to add the Metric.

The [instruction adherence](/concepts/metrics/response-quality/instruction-adherence) Metric measures how closely the model's output matches the instructions in the prompt.

![Add Instruction Adherence Metric](/images/console-ui/instruction-adherence-metric.png)
