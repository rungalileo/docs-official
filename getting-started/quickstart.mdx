Welcome to Galileo! This quickstart guide will walk you through setting up **your first AI evaluation**. You'll learn how to identify and fix an issue in AI responses using Galileo's powerful metrics.

This guide works with Python or TypeScript, using OpenAI, Azure OpenAI service, or Anthropic LLMs.

## What you'll do

In this get started guide, you will:

- Sign up for Galileo
- Set up an LLM integration to evaluate LLM-as-a-judge metrics
- Create a new project and Log stream
- Configure metrics for your Log stream
- Create a basic application to send traces to the Log stream from an LLM interaction
- Evaluate the response from the AI using a metric
- Improve your app to get a better response from the LLM
