## What you'll do

In this get started guide, you will:

- [Sign up for Galileo](#sign-up-for-galileo)
- [Set up your LLM integration](#set-up-your-llm-integration) to evaluate LLM-as-a-judge metrics
- [Get your API key](#get-your-api-key)

## Sign up for Galileo

If you haven't signed up for Galileo do so now.

<Note>
These steps are to sign up for a free Galileo account. If you are in an organization that has a custom Galileo deployment, contact your Galileo administrator to create an account.
</Note>

<Steps>
<Step title="Create an account">
Head to [app.galileo.ai/sign-up](https://app.galileo.ai/sign-up), and create a new account, either using your Google account, or with user name and password.
</Step>
<Step title="Give your organization a name">
Set the name for your organization in Galileo. This should be your company name.
</Step>
</Steps>

You will now be logged in to Galileo in your new organization.

<Note>
Each new Galileo organization contains two sample projects. If you want to learn more about these projects, check out our [sample projects guide](/getting-started/sample-projects/sample-projects) to learn more about the sample projects.
</Note>

## Set up your LLM integration

To use an LLM to evaluate LLM-as-a-judge metrics, you need to configure an integration.

<Steps>
<Step title="Open the integrations page">
Select the user menu in the top right, then select **Integrations**.

<Columns cols={2}>
![The integrations menu](/snippets/content/get-started/user-menu-integrations.webp)
</Columns>
</Step>
<Step title="Add an integration">
Locate the option for the LLM platform you are using, then select the **+Add Integration** button.

![The add integration button](/snippets/content/get-started/openai-integration-selected.webp)
</Step>
<Step title="Add the settings">

Set the relevant settings for your integration, such as your API keys or endpoints. Then select **Save**.

![The OpenAI integrations pane](/snippets/content/get-started/openai-integration-api-key.webp)
</Step>
</Steps>

The configured LLM integration will be used for evaluating LLM-as-a-judge metrics, for running experiments with prompt templates, and to autogenerate custom metric prompts.

## Get your API key

You will need your Galileo API key to be able to send traces to a Log stream fro your applications or run experiments in code.

<Steps>
<Step title="Open the API keys page">

Select the user menu in the top right, then select **API Keys**.

<Columns cols={2}>
![The API key menu](/snippets/content/get-started/user-menu-api-key.webp)
</Columns>
</Step>
<Step title="Create a new API key">
Select the **+Create new key** button to create a new API key.

![The create new API key button](/snippets/content/get-started/create-new-api-key-button.webp)

</Step>
<Step title="Name your API key">

Give your API key a name, and optionally set an expiry date. By default API keys expire after a year.

![The create API key dialog](/snippets/content/get-started/create-api-key-dialog.webp)
</Step>

<Step title="Copy your API key">

Copy your API key and store it somewhere safe. You will not be able to see this key again.

![The created API key](/snippets/content/get-started/created-api-key.webp)
</Step>
</Steps>

## Create a new project and Log stream

Now you have your integration set up, you can create a [project](/concepts/projects) and default Log stream.

Projects allow you to logically group Log streams and experiments. For example, you might have a project for an application you have deployed, with Log streams for the different environments, dev, staging, and production.

<Steps>
<Step title="Create a project">
Select the **+ New Project** button to create a new project.

![The new project button](/snippets/content/get-started/new-project-button.webp)
</Step>
<Step title="Name your project and Log stream">
Give your project a name. Each project needs at least one Log stream, so you can also set the name here, or leave it as the default.

![The create project dialog](/snippets/content/get-started/create-project-dialog.webp)

Once you have set the project and Log stream name, select the **Create project** button to create the project. This project will then be opened.
</Step>
</Steps>
