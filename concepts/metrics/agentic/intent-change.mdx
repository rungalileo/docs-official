<DefinitionCard>
<strong>User Intent Change</strong> checks if users are using your agent system for different intents across multi-turn interactions.
</DefinitionCard>

<SupportedModalities modalities={["Text", "Image/PDF", "Audio"]} />

User Intent Change is a binary evaluation metric, and is defined as a significant shift in the user's primary conversational goal or workflow during a session, relative to their initial stated intent.

This is a **boolean** metric that indicates whether the user's intent changed significantly.
