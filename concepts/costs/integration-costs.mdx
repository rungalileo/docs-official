---
title: Integration Costs
---

The **Integration Costs** page allows organization users to track project costs for [decision model](/concepts/metrics/custom-metrics/custom-decision-model-metrics) and [LLM-as-a-judge](/concepts/metrics/how-llm-as-judge-metrics-are-calculated) metrics.

In the Galileo UI, select your user profile and select **Integration costs** to access the page.

![Integration Costs](/images/console-ui/integration-costs.png)

The Integration Costs page is visible to all users in the organization as a read-only view.
