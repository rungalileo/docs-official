---
title: Log Multimodal Traces
description: Log images, audio, and documents alongside text in your traces
---

Modern AI applications go beyond text. A voice assistant processes audio. A document
pipeline analyzes PDFs. An image moderation system evaluates visual content. To
observe, debug, and evaluate these applications, you need your traces to capture the
full context of what your model sees — not just the text.

Galileo supports logging multimodal content alongside text in your traces, so you can:

- inspect the exact image, audio clip, or document your model received
- evaluate quality and behavior using multimodal metrics
- debug failures with full input context, not just text representations

---

## Before you begin

Install the Galileo Python SDK and set your API key:

```bash
pip install galileo
```

```bash
GALILEO_API_KEY=your-api-key
```

---

## Choose a logging method

If you are logging directly in your own code, use the **GalileoLogger**.

If your app already uses LangChain, use the **LangChain handler** —
multimodal content is converted automatically with no extra setup.

---

## Option 1: Log with GalileoLogger

Import the content block types you need:

```python Python
from galileo.logger import GalileoLogger
from galileo.schema.content_blocks import TextContentBlock, DataContentBlock
```

### From a URL

```python Python
logger = GalileoLogger()
logger.start_trace(
    input=[
        TextContentBlock(text="Describe this image"),
        DataContentBlock(modality="image", url="https://example.com/photo.png"),
    ],
    project="my-project",
)
logger.add_llm_span(
    input=[{"role": "user", "content": "Describe this image"}],
    output={"role": "assistant", "content": "It's a cat."},
    model="gpt-4o",
)
logger.conclude(output="It's a cat.")
logger.flush()
```

### From a local file

Encode local files using base64 and pass them with the `mime_type` field:

```python Python
import base64
from pathlib import Path
from galileo.logger import GalileoLogger
from galileo.schema.content_blocks import TextContentBlock, DataContentBlock

image_b64_data = base64.b64encode(Path("photo.png").read_bytes()).decode()
audio_b64_data = base64.b64encode(Path("recording.wav").read_bytes()).decode()
pdf_b64_data   = base64.b64encode(Path("report.pdf").read_bytes()).decode()

logger = GalileoLogger()
logger.start_trace(
    input=[
        TextContentBlock(text="Analyze all of these files"),
        DataContentBlock(modality="image",    base64=image_b64_data, mime_type="image/png"),
        DataContentBlock(modality="audio",    base64=audio_b64_data, mime_type="audio/wav"),
        DataContentBlock(modality="document", base64=pdf_b64_data,   mime_type="application/pdf"),
    ],
    project="my-project",
)
logger.add_llm_span(
    input=[{"role": "user", "content": "Analyze all of these files"}],
    output={
        "role": "assistant",
        "content": "The image shows a cat, the audio is a piano note, and the PDF is a quarterly report.",
    },
    model="gpt-4o",
)
logger.conclude(
    output="The image shows a cat, the audio is a piano note, and the PDF is a quarterly report."
)
logger.flush()
```

Supported modalities for `DataContentBlock`: `image`, `audio`, `document`.

## Option 2: Log with the LangChain handler

```python Python
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage
from galileo.handlers.langchain import GalileoCallback

callback = GalileoCallback()
llm = ChatOpenAI(model="gpt-4o", callbacks=[callback])

response = llm.invoke([
    HumanMessage(content=[
        {"type": "text",      "text": "What's in this image?"},
        {"type": "image_url", "image_url": {"url": "https://example.com/photo.png"}},
    ])
])
```

Supported content types: `text`, `image_url`, `audio_url`, `document_url`,
`input_image`, `input_audio`. Base64 data URIs are also supported — the handler
extracts the payload and mime type automatically.

## View multimodal content in your traces

Multimodal content appears inline in your Log stream alongside span input and output:

- **Audio** renders as an inline waveform player you can play back directly in the
Log stream, and can be downloaded for local review
- **Images** are displayed inline and can be downloaded
- **PDFs** appear as inline previews and can be downloaded

## Evaluate multimodal traces

Galileo provides various metrics to evaluate multimodal content: out-of-the-box
multimodal LLM-as-a-judge metrics, and custom LLM-as-a-judge metrics on spans,
traces and sessions with multimodal content.

### Out-of-the-box metrics

Enable these directly on your Log stream — no configuration needed:

| Metric | Modality | What it evaluates |
| :--- | :--- | :--- |
| **Visual Quality** | Image / PDF | Whether input quality is sufficient for the task to be reliably performed |
| **Visual Fidelity** | Image / PDF | Whether a generated image complies with brand rules, based on visible evidence |
| **Interruption Detection** | Audio | Turn-taking violations — agent overlap, premature barge-in, and user barge-in |

[See all preset multimodal metrics →](/concepts/metrics/multimodal-quality/multimodal-quality-overview)

### Custom LLM-as-a-judge metrics

1. Go to **Metrics** and create a new custom LLM metric.
1. Under capabilities, select **Image/PDF** or **Audio**.
1. Configure a model integration. See [recommended models](#recommended-models) below.
1. For Vertex AI, configure a separate GCP bucket and credentials for file uploads.
1. Enable the metric on your Log stream **before** logging content.

<Note>
Metrics are only computed when the trace contains at least one attachment matching
the enabled capability. A metric with **Image/PDF** enabled returns N/A if the trace
contains only audio, or no attachments at all.
</Note>

## Known limitations

- API readback returns `List[ContentBlock]` as JSON-stringified strings rather than
native list objects. The data is complete and parseable.
- The LangChain handler stores the full serialized message list on the trace. Content
blocks are nested inside the message's `content` field rather than at the top level.
- Recompute is not currently supported for multimodal metrics.
- Multimodal metrics are not supported in playground or prompt experiments.

## Reference

### Supported formats

| Modality | Formats |
| :--- | :--- |
| Image | `png`, `jpeg`, `mp4` |
| Audio | `mp3`, `wav` |
| Document | `pdf` |

### Recommended models

| Modality | Provider | Recommended model |
| :--- | :--- | :--- |
| Image / PDF | OpenAI | `gpt-4.1` or later |
| Audio | Vertex AI | `gemini-2.5` or later |
