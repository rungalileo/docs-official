## Overview 

When you run a [code experiment](/concepts/experiments/running-experiments), Galileo's `run_experiment` function generates logs for you. Every user input/LLM output combination creates a trace, showing what happened in that step. But what if you want more detailed logs?

In this document, we will explore how to take advantage of Galileo's logging techniques with code experiments. 

## Before you begin

If you haven't done so already, follow the [quickstart guide](/getting-started/quickstart) to setup a simple Galileo project. Here's a list of dependencies for the examples below: 

<CodeGroup>
    ```bash Python
    pip install "galileo[openai]" python-dotenv 
    ```
    ```bash TypeScript
    npm i -s galileo openai dotenv
    ```
</CodeGroup>

You should also be familiar with creating chat completion messages with <Tooltip tip="If you are using TypeScript, your project should include openai as a dependency">`OpenAI`</Tooltip>


## What we will be doing

Our experiment will ask the LLM for a short, humorous sentence about a fictional world. When we run the experiment, each entry in the dataset will be used to invoke our LLM-call function. In order to achieve this, we will need: 

1. A list of fictional worlds for our dataset
1. A tool that the LLM will use to retrieve the world's description from a mock database
1. A custom function to invoke the LLM

We will explore the two ways you can achieve similar goals in your application: by invoking the [Chat Completion API](#1-add-custom-traces-with-galileologger) with a JSON tool description, as well as using an agent with a tool function. 

## Experiment Data 

When running a code experiment, you can use a [previously-uploaded dataset](/concepts/datasets#path-1%3A-creating-and-managing-datasets-via-ui) from the Galileo Console, or an "inline" one that you describe in code. Our examples below will use inline datasets, though you can adapt this to suit your application.

## 1. Add custom traces with `GalileoLogger`

For our first example, we will use the `GalileoLogger` class to create a logging session for our experiment. We will add traces and spans to the session to identify individual events in the application flow. This example will use the ChatCompletions API.

If you're in a hurry, you can take a look at the [full code sample](#fictional-world-chat-full), then return to review the steps for a breakdown. Otherwise, we can begin by importing everything that we will need:

### Import dependencies

<CodeGroup>
    ```python Python 
    import os
    import re
    
    from dotenv import load_dotenv
    from galileo import GalileoLogger
    from galileo.experiments import run_experiment
    from galileo.openai import openai

    # Load environment variables (Galileo project, API keys, etc)
    load_dotenv(override=True)
    ```

    ```typescript TypeScript 
    import { configDotenv } from "dotenv";
    import { GalileoLogger, runExperiment, wrapOpenAI } from "galileo";
    import OpenAI from "openai";

    configDotenv();

    // Create a wrapped instance of OpenAI for typescript

    ```
</CodeGroup>
